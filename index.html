Data Science & Machine Learning

Peran: Data Analyst / ML Developer (Kelompok 4) | Tech: Python (Pandas, Scikit-Learn, Seaborn), Google Colab, Streamlit Dashboard

Penelitian supervised learning untuk memprediksi tingkat performa akademik mahasiswa berdasarkan pola kebiasaan harian (screen time, jam belajar, kualitas tidur, dan kesehatan mental).

3. Smart Energy Monitoring & Real-Time Cost Estimation System

Peran: Hardware Assembly, Circuit Design & Tech Documentation (Kelompok 2) | Tech: ESP32, PZEM-004T, DHT11, Relay, MQTT (HiveMQ Cloud), Flask API, Tailwind CSS

Sistem pemantauan parameter daya listrik dan suhu panel secara real-time berbasis IoT yang dilengkapi perhitungan estimasi tarif listrik (Rupiah) serta fitur proteksi keamanan otomatis.

Precision Sensing & Protection: Pengukuran Tegangan (V), Arus (A), Daya (W), Energi (kWh), serta fitur automatic cut-off relay jika terjadi overload (≥500W) atau overheat (>45°C).
Cloud & Dashboard Integration: Integrasi MQTT HiveMQ Cloud ke web dashboard responsif untuk visualisasi tren daya dan perkiraan biaya.
